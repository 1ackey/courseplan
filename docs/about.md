# 关于本站
## 为什么做这个

其实初心很简单，作者本人在参加教务处新系统试用的时候提过建议,看看能不能加入一个预览课程内容的功能但是迟迟没有得到回复，新系统也没看到苗头，鉴于实在看不下去我校老选课系统过于“精简”的信息，加上近段时间有心力和精力（主要是agent太好用）就学习隔壁某985的形式尝试自己为学院做一点贡献。希望有精力的同学们积极更新内容，唯有源头活水来，大家一起参与到这个网站的贡献中才能都有的用。

## 信息可靠吗

- 所有课程信息来源于**教师在课程群里发布的教学进度表**
- 每次更新都会标注信息来源（学年、学期）
- 不包含主观评价，只展示客观事实

## 我们能做的

- 如果你上过某门课且有教学进度表，欢迎[贡献](contributing.md)
- 如果发现信息有误，欢迎提交 issue 或直接修正
- 把这个网站分享给需要的同学

## 我们不做的

- 不提供课程的「好/坏」评价
- 不记录给分情况、挂科率
- 不推荐/不排序任何课程
- 不提供电子版课件和参考资料，如若可以会给出参考书目（因为我想尽可能让这个网站多活一会）
