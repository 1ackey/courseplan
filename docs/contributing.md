# 贡献指南

想为我们提供课程信息？很简单：**直接把老师的教学进度表文件发给我们即可。**

---

## 你需要做的（只需一步）

将任课老师发放的**教学进度表文件**（通常是 `.doc` 或 `.docx` 格式）作为附件发送到：

> **ja0key@qq.com**

邮件主题建议格式：`[课程投稿] ENG820 语用学 - 向明友`

---

## 不需要做的

- 不需要注册账号
- 不需要会 Git 或 Markdown
- 不需要手动排版、不需要填写表单
- 不需要注明任何个人身份信息（可以选择匿名）

---

## 收到文件后我们会

1. 核查文件中的课程信息是否完整、准确
2. 将教学进度表内容整理录入网站
3. 更新网站展示

整个过程由管理员完成，你只需要发邮件这一步。

---

## 其他贡献方式

如果你熟悉 GitHub 和 Markdown，也可以通过 Pull Request 直接添加课程文件，参考 [导入指南](import-guide.md)。

---

## 信息源说明

我们只收录**教师正式发放的教学进度表**中的信息，以确保内容准确可靠。请勿提交个人笔记或主观评价。

如有疑问或建议，欢迎发送邮件至 ja0key@qq.com。
