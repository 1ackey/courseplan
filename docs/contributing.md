# 贡献指南

## 方式一：网页直接编辑（推荐）

每一门开课记录页面的顶部都有 **「✏️ 编辑本页信息」** 按钮：

1. 打开你想补充的课程页面（先选课程，再选具体老师×学期的开课记录）
2. 点击「编辑本页信息」
3. 像填表单一样修改考核方式、教学进度等内容（教学进度支持直接粘贴老师的进度表）
4. 提交即可

根据网站当前的管理模式，你的修改可能**立即生效**，也可能**先经管理员审核后发布**——提交时页面会有提示。

## 方式二：新增一门课的开课记录

在课程总览页点击 **「提交新开课记录」**，填写老师、学期和教学进度即可。

## 方式三：邮件投稿

将任课老师发放的**教学进度表文件**作为附件发送到：

> **ja0key@qq.com**

邮件主题建议格式：`[课程投稿] ENG820 语用学 - 向明友`

---

## 其他贡献方式

如果你熟悉 GitHub 和 Markdown，也可以通过 Pull Request 直接添加课程文件，参考 [模板](course-template.md)。
注意：**数据库是网站的唯一数据源**，直接改动 Markdown 文件会在下次发布时被覆盖，因此建议优先使用网页编辑。

我们只收录**教师正式发放的教学进度表**或客观回忆记录，以确保内容准确可靠。请勿提交过于主观的评价。

如有疑问或建议，欢迎发送邮件至 ja0key@qq.com。
