# 管理员：课程信息导入指南

本文档供管理员使用，介绍如何将课程信息导入数据库并发布到网站。

---

## 整体流程

```
Excel / Google Sheets 编辑数据
        │
        ▼
   CSV 文件上传
        │
        ▼
   Flask 管理后台导入
        │
        ▼
   一键导出 → MkDocs Markdown → 网站发布
```

---

## 第一步：启动管理后台

```bash
.venv/bin/python admin/app.py
```

浏览器访问 `http://localhost:5000`

---

## 第二步：准备基础数据

在导入教学进度之前，需要确保以下基础数据存在：

### 2.1 添加教师

左侧菜单 → **教师管理** → **+ 添加教师**，填写：
- 姓名（必填）
- 所属院系（如：英语学院 · 语言学系）
- 职称（如：教授）

### 2.2 添加学期

左侧菜单 → **学期管理** → **+ 添加学期**，填写：
- 学期名称（如：`2025-2026-2`，格式：学年-学期序号）
- 学年（如：`2025-2026`）
- 学期（第一学期=秋季 / 第二学期=春季）

### 2.3 课程已预置

数据库中已包含 106 门课程（来自 2023 级培养方案），无需手动添加。如需新增课程，进入**课程管理**。

---

## 第三步：创建开课记录

### 方式一：网页表单（少量课程推荐）

左侧菜单 → **开课记录** → **+ 新增开课记录**

选择课程 + 教师 + 学期，填写总课时、周课时、教学周数、考核方式，保存。

然后点击**详情**，在详情页直接在线填写每周教学计划。

### 方式二：CSV 批量导入（大量课程推荐）

这是**最快**的批量导入方式。

#### 3.1 下载模板

左侧菜单 → **CSV 导入导出** → **下载导入模板**

得到 `weekly_plan_template.csv`：

| course_code | teacher_name | semester_name | week_number | date | hours | teaching_method | content | notes |
|-------------|-------------|---------------|-------------|------|-------|-----------------|---------|-------|
| ENG820 | 向明友 | 2025-2026-2 | 1 | 3.11 | 2 | 研讨 | Introduction | 教师主讲 |

#### 3.2 在 Excel 中编辑

1. 用 Excel / WPS / Google Sheets 打开 CSV 文件
2. 按模板格式填写数据，每一行是一个教学周
3. **保存为 CSV UTF-8 格式**

**关键说明：**
- `course_code`、`teacher_name`、`semester_name` 必须与数据库中的数据**完全一致**
- 如果开课记录（课程+教师+学期）不存在，该行会被跳过
- 先通过管理后台创建开课记录，再用 CSV 批量导入教学进度

#### 3.3 上传导入

左侧菜单 → **CSV 导入导出** → **上传并导入**

选择刚编辑好的 CSV 文件，点击上传。

---

## 第四步：导出到网站

导入完成后，在管理后台点击左侧 **导出 Markdown** → **执行导出**。

这会自动：
1. 从数据库生成所有课程的 Markdown 文件
2. 更新分类索引
3. 更新教师索引
4. 更新网站侧边栏导航

---

## 快速导入命令（一键操作）

如果你有批量数据（例如一份 Excel 表格记录了所有课程的教学进度），最快的方式是直接在命令行运行导出，整个流程：

```bash
# 1. 启动管理后台
.venv/bin/python admin/app.py

# 2. 浏览器打开 http://localhost:5000
# 3. 进入 CSV 导入导出 → 上传 CSV 文件
# 4. 进入 导出 Markdown → 执行导出
# 5. 本地预览（可选）
.venv/bin/mkdocs serve
```

## CSV 列说明

| 列名 | 必填 | 说明 | 示例 |
|------|------|------|------|
| `course_code` | 是 | 课程代码 | `ENG820` |
| `teacher_name` | 是 | 教师姓名（需与数据库一致） | `向明友` |
| `semester_name` | 是 | 学期名称（需与数据库一致） | `2025-2026-2` |
| `week_number` | 是 | 教学周次 | `1` |
| `date` | 是 | 日期 | `3.11` |
| `hours` | 否 | 课时数，默认 2 | `2` |
| `teaching_method` | 否 | 教学方式 | `研讨` |
| `content` | 是 | 内容提要 | `Defining Pragmatics` |
| `notes` | 否 | 备注 | `教师主讲` |

## 常见问题

**Q: 导入后 CSV 中的中文变乱码？**
A: CSV 文件必须保存为 **UTF-8** 编码。Excel 中：文件 → 另存为 → 选择 CSV UTF-8。

**Q: 提示「该课程-教师-学期组合已存在」？**
A: 同一个课程+教师+学期的开课记录只能有一条。如需要更新，请在管理后台编辑已有记录。

**Q: 如何在 Excel 中快速生成 16 周的教学计划？**
A: 先在管理后台创建开课记录，然后用 Excel 拖拽填充 week_number 1-16，修改每行的 content 即可。
