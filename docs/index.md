# 去码头整点英语

## 这是什么？

UIBE当前的选课系统只列出课程名称，**不展示课程内容和考核方式**，

老师们在开课后都会发放**教学进度表**（包含每周教学内容、教学方式等详细信息），但这些信息只能在选课后才能看到。

**本平台将往年的教学进度表整理**，希望大家在选课前就能了解每门课的真实面貌。

## 如果你是同学

> 选课应基于内容本身。不提供评分、不排名、不记录给分情况。
> 这里只有课程内容，我们不希望提供主观舆论发酵的场所 —— 我们希望大家都能在惠园找到自己的路线。

## 如果你是任课老师

> 本网站不提供课程PPT和课程电子版资料，如果仍冒犯到您或您有对于课程其他的考量不希望展示自己先前的教学进度表，请联系< ja0key@qq.com >，我们会第一时间删除
> 如若您对本网站有什么意见或者修改建议，也可以以相同的方式联系我们

## 快速入门

1. **搜索**：在上方搜索框输入课程名称、代码或教师名
2. **浏览**：点击左侧导航栏链接按类别浏览所有课程
3. **贡献**：有你上过的课还没有收录？把老师的教学进度表发到 ja0key@qq.com，[查看详情](contributing.md)
