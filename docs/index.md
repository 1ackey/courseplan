这是一个展示**UIBE英语学院**开设的对内课程的课程基本信息文档网站，你校不公开课程基本信息的这个坏习惯我实在看不下去了，大家如果不知道这节课的基本内容，就只能靠神秘群聊和神秘匿名墙了，更何况有些课程根据上课老师不同上课内容有所创新和差别，毕竟谁能想到有些课居然会有9次pre（恼）/有些课程教的东西全国找不出来类似的课程
